Interpretability

Making the evidence behind a machine-generated text prediction visible, and testing whether that evidence is actually useful.

Problem

A detector can tell us whether it thinks a passage is human-written or machine-generated. That prediction alone, however, does not show what in the passage supported the decision.

This matters when a prediction needs to be checked or justified. Our approach is to use a rationale: a selected part of the input that the predictor actually uses to make its decision. Instead of giving the predictor the complete passage, a selector chooses which token positions remain available to it.

Making that evidence visible creates two separate questions. Can the detector still perform well when it only receives selected text? And if those selected words are useful to the model, are they also useful to a person trying to judge whether the passage was written by a human or generated by a language model?

Research Question

Can a rationale-based classifier retain detection performance relative to a matched full-context classifier while exposing evidence that matters to its prediction, and does showing that evidence help human evaluators judge authorship?

Method

We use an English subset of RAID containing 8,160 passages, split evenly between human-written and machine-generated text. The passages come from abstracts, books, news and poetry, while the machine-generated half covers six generator labels.

Dataset
8,160 passages: 4,080 human and 4,080 machine
Data split
5,760 training · 1,200 validation · 1,200 test
Visible context
Up to 512 tokens from each passage
Rationale budget
40% of the visible token positions
Main comparison
Rationale BiLSTM against a matched full-context BiLSTM
Other comparisons
TF-IDF baseline and full-context / rationale Transformer models

Selector and predictor

The rationale model contains two separate BiLSTMs. The selector reads the visible passage and decides which token positions to keep. The predictor then makes the human-versus-machine decision from the selected token content.

At evaluation time, the selector keeps 40% of the visible positions. Tokens that are not selected are zeroed before they reach the predictor. This means the predictor cannot use their token content, although their positions remain in the sequence.

Testing the selected evidence

A model could perform well simply because it is still given enough text. To check whether the particular words selected by the model matter, we compare the learned rationale with random selections and with tokens taken from the beginning or end of the passage. Every comparison keeps the same number of tokens.

We also test how much the prediction changes when the selected evidence is removed, and how similar the selected token positions are across independently trained models.

Human study

The human study uses 20 passages from the test set. Each participant sees ten passages and judges each one as Human, Machine or Cannot tell. A passage can be shown as plain text, with the model's rationale highlighted, or with the same number of tokens highlighted at random.

Twenty-five participants took part, giving 250 retained judgements.

Results

Detection performance

The rationale BiLSTM reached 94.5% F1 while using only 40% of the visible text.

The matched full-context BiLSTM reached 95.5% F1. The difference between them was 0.97 percentage points, so restricting the predictor to selected evidence resulted in only a small loss in detection performance.

Model F1 AUROC
TF-IDF 94.9% 98.9%
Full-context BiLSTM 95.5% ± 0.4% 98.9% ± 0.1%
Rationale BiLSTM 94.5% ± 0.4% 98.6% ± 0.0%
Full Transformer 96.4% ± 0.2% 98.9% ± 0.0%
Rationale Transformer 93.2% ± 0.3% 97.7% ± 0.3%

Neural results are reported as mean ± standard deviation across three training seeds.

Did the selected evidence matter?

Yes. The predictor performed substantially better with the learned rationales than with equally sized alternative selections.

Because every control keeps the same number of tokens, the difference comes from which text was selected rather than simply how much text the predictor received.

Selection F1
Learned rationale 94.5% ± 0.4%
Random 86.6% ± 4.4%
First tokens 77.5% ± 2.0%
Last tokens 78.6% ± 5.2%

Dependence. Removing the selected rationale reduced predicted-class confidence by 0.516 on average.

Stability. The mean pairwise Jaccard similarity between selected token positions was 0.633.

Prediction agreement. The three independently trained models gave the same predicted class for 94.1% of the test passages.

The predictions were therefore more consistent across training runs than the exact evidence selected for them.

Did the rationales help people?

We found no clear evidence that showing the learned rationales improved human authorship judgements.

Participants performed similarly whether they saw the passage as plain text, with the detector's rationale highlighted, or with random highlighting.

Condition Judgements Raw accuracy Cannot tell
Plain 83 47.0% 9.6%
Detector 82 45.1% 8.5%
Random 85 44.7% 15.3%

The statistical analysis reached the same conclusion. The confidence intervals were wide, and neither the Detector-versus-Plain nor Detector-versus-Random comparison showed a clear advantage for the learned highlighting.

Discussion & Conclusion

The main result is that strong detection remained possible even when the predictor was restricted to selected evidence. The rationale BiLSTM gave up less than one percentage point of F1 relative to the matched full-context model while using only 40% of the visible text.

The control experiments also show that the selector was not simply keeping an arbitrary 40% of the passage. The learned selections performed much better than random, first-token and last-token selections of the same size, and removing the selected evidence substantially reduced model confidence.

At the same time, the exact rationale was less stable than the final prediction. Different training runs often reached the same classification while selecting somewhat different token positions.

The human study adds another distinction. Evidence can be useful to the predictor without automatically being useful to the person reading it. In this study, showing the learned rationales did not clearly improve human authorship judgements over plain text or random highlighting.

Main takeaway: evidence that is useful to the model is not necessarily useful to a human reader.

These results describe the conditions tested here. The study uses English passages from domains and generators represented during training, and the human evaluation is based on 25 participants. Testing unseen generators, new domains and larger or more specialised participant groups remains future work.
